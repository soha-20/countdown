## Problem
The student needs constant reminders about the events for example finals coming or upcoming winter breaks. Calenders shows dates, not how much time is left, so e.g "dec 3" doesn't feel urgent until it is tomorrow. For this purpose the command-line countdown can be a good resource to keep updating them so that they can plan accordingly about this.

## Initial Requirements
- R1:Add an event with the name and event
- R2: See all events with the days remaining, sorted from soonest to latest
- R3: Tell at a glance which events are urgent
- R4: Remove or edit an event
- R5: Keep events saved between sessions
- R5: Easier for user to read and understand the urgency of upcomin events

## Added Requirements
- R7: Interactive, user-friendly menu so events can be managed without remembering commands
- R8: Visual display with colors: title banner, boxed table colored by urgency, and an alert line for urgent events
